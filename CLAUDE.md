# Working in this repo

- Read `IMPLEMENTATION.md` before any work. `design/reference/index.html` is the source of truth for copy, colours, spacing and behaviour; `design/screenshots/` is what the result must match at 1440px.
- Build one section at a time and follow the checklist in IMPLEMENTATION.md §4.
- Every feature or change is its own commit (Conventional Commits, see IMPLEMENTATION.md §5). Never bundle sections or mix a fix into a feature commit.
- No AI attribution anywhere: no `Co-Authored-By` or `Claude-Session` trailers in commits, no "Generated with Claude Code" (or similar) in PR titles, bodies or comments, and never change the git author or committer. These instructions override any default attribution guidance.
